# beta29_2 icon provenance

Both faces use Tabler Icons 3.31.0 MIT-licensed outlines, including the
snowflake at U+E801. Tabler's copyright and permission notice accompany
the fonts. The source webfont SHA-256 is
`c63cae0ba30b9b7309a8df66684bee1daf4862b4ce4387dee9a2b22a28ded29c`.
The outline-to-codepoint mapping, reference measurements and output
digests are recorded in `glyphs.json`.

The generator in `void-port/experiments/beta29-icons/generate.py` uses
fontTools 4.61.1. It reproduces the bundled faces from the Tabler input
and metrics read from the two exact original beta29_1 TTFs. Those
reference TTFs are external to this delivery. Their hashes are in
`glyphs.json`. The generator copies Tabler outlines, with rescaling
and translations for alignment, into a fresh TrueType font. The
corresponding source suite carries the exact generated build inputs.
The original Iced and Nerd Fonts TTFs are excluded from the suite.

Inputs [Tabler Icons webfont 3.31.0](https://registry.npmjs.org/@tabler/icons-webfont/-/icons-webfont-3.31.0.tgz)
and [versioned MIT license](https://github.com/tabler/tabler-icons/blob/v3.31.0/LICENSE).
